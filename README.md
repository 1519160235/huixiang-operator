# 回响

让 MaiBot 替你逛小黑盒：自己刷帖、评论互动、挑分区发帖配图，没什么想说的就这一轮不发。

- 插件 ID：`local.huixiang-operator`
- 运行宿主：MaiBot ≥ 1.4.0（宿主 SDK ≥ 2.8.0）
- 仓库：<https://github.com/1519160235/huixiang-operator>
- 许可证：MIT

> 非官方工具，通过模拟客户端请求访问小黑盒接口，存在账号风险。建议先开演练模式、用小号试。

---

## 它能做什么

**刷帖与互动**

- 定时浏览推荐流和你指定的分区，看到值得回的帖子才回。
- 有人 @ 或回复会接话，同一条通知不会回两遍。
- 评论用真实社区表情，表情白名单能从真实评论里自动扩充。

**发帖**

- 先自问「想发点什么吗」，不想发就跳过，不硬凑内容。
- 8 种发帖动机轮换（刷到好玩的、想吐槽、想问、想安利……），最近几篇不重复同一种。
- 自动挑分区、配话题、生成配图；标题会跟最近 6 篇做去重。
- 写完做接地检查：正文提到素材里没有的作品或事件，整篇作废重写，宁可不发也不编。

**护栏**

- 发帖 / 评论 / 点赞 / 回复分别有每日额度。
- AI 味打分、内容去重、验证码熔断。
- 平台明确拒绝时自动停手进入冷却，不会一直重试白烧模型和生图的钱。

**出问题会通知你**

平台限制写功能、登录失效、配图签名过期这三类情况会推一条消息到 **Server 酱**（微信），不用天天翻后台日志。

## 安装

**方式一：插件市场（推荐）**

MaiBot WebUI → 插件市场 → 搜索「回响」→ 安装 → 重启。

**方式二：手动**

1. 把仓库放到 MaiBot 的 `plugins/` 下，目录名保持 `huixiang-operator`。
2. 重启 MaiBot，日志出现「回响：插件已加载」即为成功。
3. 打开插件设置页，**先保持运行模式 = 演练**。

依赖（`httpx`、`qrcode`、`pillow`、`pydantic`、`cryptography`）由宿主统一安装，不用手动装。

## 上手三步

**1. 登录**

聊天里发：

```
/hx_login
```

按提示扫码（二维码会直接出图），凭据只存在本地数据目录，不写配置、不进日志。
扫完用 `/hx_login_check` 确认。

**2. 演练**

保持「演练」模式跑几轮，用 `/hx_summarize` 看它这一轮会不会想发、会写成什么样。
演练不发真实请求、不占额度。

**3. 开自动**

确认行为符合预期后，把 `[basic].mode` 改成「自动」、`[basic].enabled` 打开。

## 常改的配置

| 配置项 | 说明 | 默认 |
|---|---|---|
| `[basic].enabled` | 启用插件 | `false` |
| `[basic].mode` | 演练 / 自动 | `演练` |
| `[publish].default_partition` | 默认发帖分区 | 空（按正文命中） |
| `[image].with_image` | 发帖带配图 | `true` |
| `[guard].daily_quota_post` | 每日发帖上限 | `3` |
| `[sense].pause_on_sleep` | 睡觉时不发 | `true` |
| `[links].serverchan_key` | Server 酱 SendKey（收告警） | 空 |

其余字段在插件设置页都有中文说明，完整清单见 [`docs/配置说明.md`](docs/配置说明.md)。

### 配图接口

配图走任意 OpenAI 兼容接口，地址和模型已预填，装完只差一个 key：

```toml
[image]
image_api_base_url = "https://ai.feiyuapi.top/v1"   # 已预填，可改任意兼容接口
image_api_key = ""                                  # ← 只需要填这个
image_model = "gpt-image-2.6"                       # 已预填，支持 4K
```

不填 key 也能跑：会回退用 MaiBot 本体「画图」里配的模型。不想配图就把 `[image].with_image` 设为 `false`。

作者在用的中转站（带邀请码，双方各得少量额度返还，不影响你付的钱）：
<https://ai.feiyuapi.top/register?aff=2U5HGJJJABLJ>

### 告警推送

去 [Server 酱](https://sct.ftqq.com) 拿 SendKey，填进 `[links].serverchan_key` 即可。
不方便改配置的话，把 Key 写进数据目录的 `serverchan_key.txt` 也会生效，不用重启。

## 常用命令

| 命令 | 作用 |
|---|---|
| `/hx_status` | 今日额度、熔断状态、后台轮询 |
| `/hx_login` / `/hx_login_check` / `/hx_logout` | 扫码登录 / 检查 / 退出 |
| `/hx_browse` | 立刻刷一轮帖子（只读） |
| `/hx_interact` | 回应通知 + 评论互动 |
| `/hx_summarize` | 演练一次发帖，看会不会发、写成什么样 |
| `/hx_try_publish` | 演练试发，不占额度、不发真实请求 |
| `/hx_log` | 最近操作记录 |

后台页面提供总览、手动触发和操作记录查询。

## 常见问题

**会不会发一堆低质内容？**
不会。每轮先判断「想不想发」，额度、去重、AI 味打分、接地检查四道护栏都在发布之前。

**要一直开着电脑吗？**
不用。插件跑在 MaiBot 所在服务器上，签名也在服务器本地计算，跟你自己的电脑无关。

**会不会把我号搞封？**
有风险。这是模拟客户端请求的非官方工具，平台风控随时可能变化。建议小号、低频率、先演练。

**发不出去怎么办？**
先看 `/hx_status` 和 `/hx_log`：额度用完、冷却中、登录失效是最常见的三种原因。配了 Server 酱的话，需要你动手的情况会主动推给你。
